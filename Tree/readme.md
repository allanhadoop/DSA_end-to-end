| Level                | Program                    | What you learn             |
| -------------------- | -------------------------- | -------------------------- |
| 🟢 **Easy**          | Create a tree              | Nodes, parent, children    |
| 🟢 **Easy**          | Print tree                 | Accessing child nodes      |
| 🟡 **Medium**        | Tree Traversal             | Visit every node           |
| 🟡 **Medium**        | Count nodes / leaves       | Recursion                  |
| 🟠 **Hard**          | Binary Search Tree         | Searching efficiently      |
| 🟠 **Hard**          | Insert + Delete in BST     | Maintaining tree structure |
| 🔴 **Most Advanced** | BFS / Level-order          | Queue + tree               |
| 🔴 **Most Advanced** | Find shortest/deepest path | Recursion + comparison     |
| 🔴 **Most Advanced** | Lowest Common Ancestor     | Advanced tree reasoning    |
| 🔴 **Most Advanced** | Balanced trees             | Keeping tree efficient     |
